# Игровые предметы

Манифест содержит **450 позиций: 45 предметов для каждой из 10 локаций**.

- Формат игровых изображений: PNG с прозрачным фоном.
- Полный список, названия, позиции и пути: `manifest.json`.
- Данные локаций: `game_data/story.json`.
- Дополнительные PNG для глав 1–10 создаются сборочным скриптом `ci/level_content.py` в каталоге `packaged/assets/items`.

**Важно:** в исходной папке репозитория сейчас сохранены базовые PNG первой локации. Остальные дополнительные PNG создаются во время сборки Android-проекта, а не хранятся отдельными файлами в Git на данный момент.
