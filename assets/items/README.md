# Игровые предметы

Эта папка предназначена для отдельных PNG-изображений предметов поиска.

- Формат: PNG с прозрачным фоном.
- Ожидаемое количество: 45 изображений для уровней 2–10.
- Имена файлов и пути перечислены в `manifest.json`.
- Уровень 1 использует исходные предметы из базового проекта.

**Важно:** в текущем состоянии репозитория исходных PNG-файлов предметов нет. Здесь восстановлены структура каталога и точный манифест по `game_data/story.json`; сами оригинальные изображения не подменялись пустыми заглушками.
