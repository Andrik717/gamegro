# Игровые предметы

В репозитории хранится полный набор игровых изображений: **95 уникальных PNG** для **450 размещений** — по 45 предметов на каждой из 10 локаций.

- Формат игровых изображений: PNG с прозрачным фоном.
- Полный список, названия, позиции и пути: `manifest.json`.
- Данные локаций: `game_data/story.json`.
- `manifest_additions.json` описывает 65 дополнительных изображений, добавленных к базовым 30.

Сборка Android использует файлы непосредственно из `assets/items`; отдельная генерация предметов во время сборки не требуется.
