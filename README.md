# MagicWorld — Hidden Object: Тайна игрушечного острова

Godot 4.4 project — первый запускаемый уровень игры «найди предметы».

## Уже реализовано
- Иллюстрированный тропический остров (SVG-ассет, без внешних зависимостей).
- Поиск пяти предметов: морская звезда, ракушка, золотой ключ, ананас и краб.
- Найденные предметы скрываются, счётчик обновляется.
- Таймер, подсказка с подсветкой, пауза, экран победы и перезапуск.
- Масштабирование под разные размеры окна и сенсорный ввод.
- GitHub Actions workflow для сборки Android debug APK.

## Запуск
Откройте \`project.godot\` в Godot 4.4+ и нажмите F6/F5.

## Android
Workflow **Build Android APK** запускается при push в \`main\` или вручную через Actions. Готовый APK будет доступен в артефактах запуска.

## Примечание
Это собранная стартовая версия на основе доступного игрового замысла и сцены острова. Полного исходного дампа Grok с отдельными SVG/TSСN/GD-файлами в доступных материалах не было, поэтому этот коммит не выдаётся за восстановление отсутствующих исходников.
