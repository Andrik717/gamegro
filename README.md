# MagicWorld — Hidden Object

Проект игры на Godot 4.4.1 с Android-экспортом.

## Содержимое

- 10 локаций.
- 45 предметов на каждой локации (450 размещений).
- 95 уникальных PNG-изображений предметов.
- Данные уровней находятся в `game_data/story.json`.
- Игровая логика находится в `scripts/game.gd`.

## Сборка Android

GitHub Actions workflow **Build Android APK** собирает проект из файлов репозитория, проверяет данные уровней и импортирует проект в Godot перед экспортом debug APK.

Workflow запускается при push в `main` и `feature/**`, а также вручную через Actions.

APK публикуется как артефакт `MagicWorld-Android-debug`. Успешный статус сборки подтверждает экспорт, но не заменяет тестирование на реальном Android-устройстве.

## Проверки

- 10 уровней и по 45 уникальных предметов в каждом.
- Наличие файлов предметов и фоновых изображений.
- Импорт ресурсов и проверка GDScript в Godot.
- Экспорт Android APK.

## Известные ограничения

- Отдельные фоновые сцены пока отсутствуют для локаций 2, 4, 7, 8, 9 и 10; для них используется резервный фон первой локации.
- Сохранение расположения предметов работает отдельно для каждой локации. Сохранение общего прогресса прохождения между запусками пока не реализовано.
- Скрипты из `ci/` — устаревшие генераторы прототипа; активная Android-сборка их не запускает. Подробности — в `ci/README.md`.
