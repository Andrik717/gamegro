# MagicWorld — Тропическая бухта (уровень 1)

Проект Godot 4.4.1 для Android, альбомная ориентация.

## Что включено
- Фон уровня — предоставленная пользователем иллюстрация, включена локально.
- 30 отдельных PNG-рисунков предметов (каждый в `assets/items/`).
- Нижняя панель показывает 5 следующих предметов; после нахождения предмет исчезает из сцены и списка, а на его место выходит следующий.
- Звук находки, нажатия, подсказки и фоновый шум прибоя — локальные WAV-файлы, без внешних аудио-ссылок.
- Масштабирование двумя пальцами, перемещение двумя пальцами и прокрутка колёсиком мыши.
- Android APK workflow в GitHub Actions.

## Открытие
Откройте папку проекта в Godot 4.4.1. Для Android установите export templates и настройте Android SDK/JDK в Editor Settings → Export → Android. Затем запустите workflow `Build Android APK`.

## Важное замечание по проверке
Файлы проекта и ассеты сформированы, PNG/WAV проверены на чтение. В этой среде не установлен исполняемый Godot Editor/CLI, поэтому запуск сцены и реальную сборку APK здесь подтвердить нельзя. GitHub Actions выполнит проверку импорта ресурсов и экспорт после публикации проекта в репозитории.
