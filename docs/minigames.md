# MagicWorld — обязательные мини-игры

После нахождения всех 45 предметов локации запускается мини-игра из `game_data/minigames.json`. Пока игрок не завершит её, следующая локация остаётся закрытой.

## Типы механик

- **cleaning** — провести мышью/пальцем по грязным пятнам на артефакте. Все пятна нужно очистить.
- **assembly** — перетащить четыре четверти изображения на соответствующие квадранты контура.
- **painting** — выбрать один из пяти цветов и раскрасить пять отмеченных зон.
- **repair** — выбрать инструмент и применить его к соответствующему узлу в последовательности.

Все действия поддерживают мышь и сенсорный экран. Таймера и штрафов нет.

## Данные и сохранение

- `game_data/minigames.json` хранит название, тип, подсказку и путь к PNG артефакта для каждого уровня.
- Для артефактов переиспользуются существующие изображения из `assets/items/`; загрязнение, пазл-фрагменты, зоны раскраски и ремонтные маркеры рисуются в Godot поверх них. Это сохраняет единый художественный стиль и не добавляет случайные внешние картинки.
- `user://magicworld_progress.json` хранит пройденные уровни и индекс последней открытой локации.
- Завершение мини-игры записывает прогресс и открывает следующую локацию. Карта не позволяет перейти на закрытый уровень.

## Проверки

Android CI проверяет количество мини-игр, допустимые типы, соответствие номеров уровней и существование каждого изображения артефакта. Godot headless import проверяет синтаксис GDScript, затем workflow экспортирует debug APK.

Визуальную проверку на физическом Android-устройстве всё равно нужно выполнить отдельно.
